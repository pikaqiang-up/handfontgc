安装并使用

        
下载 TTF 后，像普通字体一样安装即可在 Word、PS、剪映等软件里使用。

      

    

    

      

        
Windows

        
右键 TTF →「安装」；或双击打开后点「安装」。重启正在使用的软件。

      

      

        
macOS

        
双击 TTF → 字体册 →「安装字体」。在 Pages / Word 的字体列表里搜索字体名。

      

      

        
手机 / 其他

        
Android 可用字体管家类工具导入；iOS 需通过描述文件或支持自定义字体的 App。

      

      

        
版权

        
字形来自你自己的书写，字体版权归你所有。本工具不收集、不上传任何照片。

      

    

  


  

    
写得好，字体才好

    

      

        01
        
用黑色笔，一笔一画

        
0.5mm 中性笔或钢笔均可。字写在格子中间，不要碰到格线，不要连笔涂改。写错的字留空，合成后单独补写即可。

      

      

        02
        
拍照比扫描更简单

        
把纸放在平整桌面，手机正对纸面。让四角黑块完整入镜，留一点白边。光线不足时用室内顶灯，避免手机影子落在纸上。

      

      

        03
        
先试 50 字，再写 3500 字

        
建议先用「自定义文字」写一小段，合成一次看看效果。满意后再打印完整字集，避免白写。字体里的字越全，日常打字越少遇到缺字。

      

    

  


  

    
常见问题

    

      一定要写满 3500 字吗？
      
不一定。只写你常用的字也可以，缺字时系统会自动用其他字体补上。字体里包含的字越多，排版时越统一。

    

    

      照片拍歪了、有阴影，会影响吗？
      
四角黑块就是用来做透视校正的，轻微倾斜没关系。严重阴影会让笔画变粗或断裂，建议重拍。合成结果页会显示缺字和异常提示。

    

    

      为什么生成的字体有些字大小不一？
      
这是手写的自然差异。勾选「自动统一字的大小」会按每个字的包围盒缩放；取消勾选则完全保留你在格子里的原始大小和位置。

    

    

      字体可以商用吗？
      
字形是你自己写的，版权归你。若字体里包含他人字库的临摹字形，请自行确认授权。本工具只做图像处理和字体打包，不提供任何字库。
