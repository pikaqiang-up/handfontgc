# 本地字体工坊

把写在纸上的字，变成可以安装、可以打字的 TTF 字体。

完全离线运行：照片、模板、生成结果都只保存在本机 `projects/` 目录，不会上传到任何服务器。

> 这是一个独立的本地实现，没有搬运第三方网站的前端代码或字体资源。核心流程为：
> 生成 A4 模板 → 拍照/扫描 → 四角定位校正 → 逐格取字 → 矢量化 → 用 fontTools 组装 TTF。

## 功能

- **A4 手写模板**：600 DPI PDF + 每页 4960×7016 高清 PNG（单页下载 / ZIP 打包），内置常用 3500 字、英文/数字/标点、自定义文字。
- **自动校正**：识别模板四角黑块，透视校正手机照片。
- **自动取字**：按模板字符顺序裁切每个字格，去噪、去格线。
- **矢量化**：调用 `potrace` 生成平滑轮廓，`fontTools` 组装 TrueType 字体。
- **大小统一**：汉字按包围盒统一大小；拉丁字母按大小写/升部/降部处理；标点按类别归位。
- **网页界面**：生成模板、上传照片、查看进度、在线预览字体、下载 TTF。
- **命令行**：适合批量制作或脚本调用。
- **自带样张**：生成 `preview.png` 和可在浏览器打开的 `specimen.html`。

## 安装

依赖：Python 3.10+、`potrace`、可显示中文的字体（Linux 下通常已安装 Noto CJK）。

Debian / Ubuntu：

```bash
sudo apt install potrace fonts-noto-cjk
cd handfont-studio
./install.sh
```

`install.sh` 会创建 `.venv` 并安装 `requirements.txt` 中的 Python 包。

## 启动网页界面

```bash
cd handfont-studio
./run.sh
```

浏览器会自动打开 <http://127.0.0.1:8765/>。只监听本机地址，按 `Ctrl+C` 停止。

也可以手动指定端口：

```bash
./run.sh --port 9000
```

## 使用流程

1. **生成模板**：选择字符集、每页行列数、字体名称，点击“生成 A4 模板”。
2. **打印或电子书写**：下载 PDF，使用 A4 纸、**实际大小 / 100%** 打印，不要勾选“适应页面”。也可以不打印，直接在平板/电脑上打开高清 PNG（或 PNG 压缩包）书写。
3. **书写**：用黑色笔在每格内写一个字。不要写出格线，不要涂改。每格上方的浅灰字是示例，写在下方空白处。
4. **拍照**：正面拍摄每一页，四角黑块必须完整入镜；光线均匀，避免阴影和反光。
5. **上传**：回到网页第 02 步，选择对应模板项目，按页序上传照片（文件名自然排序，如 `page_001.jpg`、`page_002.jpg`）。
6. **合成**：点击“开始合成字体”，等待进度完成；下载 TTF，或先在线试打。
7. **安装**：Windows 右键 TTF → 安装；macOS 双击 → 字体册 → 安装。

## 命令行

```bash
# 生成常用 3500 字模板（默认 9 列 × 12 行，33 页）
./handfont.py template --preset common3500

# 自定义文字，指定项目目录
./handfont.py template \
  --text "永和九年岁在癸丑暮春之初" \
  --out projects/my-font \
  --cols 6 --rows 6

# 用照片合成字体
./handfont.py build \
  --project projects/my-font \
  --photos photos/

# 查看字体信息
./handfont.py info --font "projects/my-font/build/我的手写体.ttf"

# 重新生成样张
./handfont.py preview --font "projects/my-font/build/我的手写体.ttf"

# 环境自检 / 模拟填写并跑通全流程
./handfont.py doctor
./handfont.py selftest
```

`--photos` 可以传目录，也可以传多个文件；目录中的图片会按文件名自然排序。

每个项目目录：

```text
projects/时间-字体名/
├── template.pdf          # 打印用 A4 模板
├── template_png.zip      # 全部高清 PNG 的压缩包
├── template/page_*.png   # 每页 600 DPI 高清图（4960×7016）
├── preview/page_*.jpg    # 网页缩略图
├── meta.json             # 字符顺序、版式、定位块坐标
├── chars.txt             # 每行一个字符
├── build/
│   ├── 字体名.ttf
│   ├── preview.png       # 字体样张
│   ├── specimen.html     # 可交互的 HTML 样张
│   ├── result.json       # 缺字、提示、处理方式
│   └── warped/           # 校正后的页面缩略图，用于检查对齐
└── uploads/              # 网页上传的原始照片
```

## 模板规格

- 纸张：A4 纵向。合成用逻辑坐标 2480 × 3508 px（300 DPI）；输出 PDF/PNG 为 600 DPI（4960 × 7016 px）。
- 四角：64 × 64 px 实心黑块，用于透视校正。
- 默认版式：9 列 × 12 行 = 108 字/页；3500 字约 33 页。
- 每格顶部 36 px 为示例字条带，书写区域在其下方。
- 可调版式：4–12 列，6–16 行。

## 拍摄与书写建议

- 先写 20–50 个字试做一次，满意后再写完整字集。
- 字写在格子中间，笔画不要碰到格线；碰线的字会被裁掉一部分。
- 拍照时留一点白边，四个黑块不要被裁掉；页面倾斜没关系，黑块会用于校正。
- 文件名按页序排列；如果顺序不对，重命名后再上传。
- 光线不均、阴影、反光会让笔画断裂或变粗，尽量在均匀顶光下拍摄。
- 缺字会在结果页列出；可以补写后重拍对应页，再重新合成。

## 常见问题

**四角黑块没识别到？**
结果页会提示“按 A4 比例裁剪”。请确认黑块没有出画、没有被手指挡住，然后重拍。`build/warped/` 里可以看到校正结果。

**有些字没提取到？**
可能是字写出了格、笔画太淡、或照片该区域有阴影。查看 `build/warped/page_*.jpg` 对齐情况，补写后重拍。

**字体里的字大小不一？**
勾选“自动统一字的大小”会按字形包围盒缩放；取消勾选则保留你在格子里的原始大小和位置。

**拉丁字母/标点位置奇怪？**
汉字按统一大小处理；拉丁字母按大小写、升部、降部给不同高度；常见中英标点会归位到基线、顶部或中部。少数不常见符号保留原始书写位置。

**生成的字体缺字怎么办？**
字体只包含模板里的字符。缺字时系统会回退到其他字体；要补字，重新生成包含这些字的模板并合成，或在字体编辑软件中合并 TTF。

**没有 potrace？**
程序会退回 OpenCV 多边形轮廓，字体能用但曲线会有棱角。建议安装 potrace。

## 隐私与版权

- 服务只绑定 `127.0.0.1`，局域网内其他设备无法访问。
- 照片只写入本机 `projects/`；不会联网上传。
- 字形来自你自己的书写，字体版权归你。若临摹了他人字库，请自行确认授权。
- 本工具不附带任何商业字库，模板里的示例字仅用于提示书写内容。

## 技术栈

- Pillow：模板排版、样张渲染。
- OpenCV：定位块识别、透视校正、二值化、连通域去噪。
- potrace：位图转贝塞尔轮廓。
- fontTools：TrueType 字体组装。
- img2pdf：把 600 DPI 页面打包为 A4 PDF。
